# Эмулятор командной оболочки UNIX (вариант 3)

Консольное приложение на Go, имитирующее работу командной строки
UNIX-подобной ОС.

## Этап 1. REPL

- Приглашение к вводу строится по реальным данным ОС: `username@hostname:~$`.
- Парсер поддерживает кавычки, экранирование `\` и раскрытие переменных
  окружения реальной ОС: `$HOME`, `${USER}`.
- Команды-заглушки `ls`, `cd` выводят своё имя и аргументы.
- Команда `exit [код]` завершает работу.

## Этап 2. Конфигурация

Параметры командной строки:

| Параметр | Описание |
|---|---|
| `--vfs PATH` | путь к физическому расположению VFS |
| `--script PATH` | путь к стартовому скрипту |

При запуске выводятся все заданные параметры (отладочный вывод).
Стартовый скрипт выполняется построчно, при этом на экран выводятся
и команды, и результат. Поддерживаются комментарии в синтаксисе Go:
`// ...` и `/* ... */`.

Скрипты для проверки параметров: `scripts/test_*.sh`.

## Сборка и запуск

```sh
make build   # сборка в bin/emulator
./run.sh     # сборка и запуск
make test    # запуск тестов
```
